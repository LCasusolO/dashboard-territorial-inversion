# Dashboard territorial de inversión

Consulta la cartera, las brechas y las potencialidades de Loreto, Madre de Dios, Puno, Tacna y Tumbes. Los 808 registros de partida corresponden a códigos CUI, Idea y SNIP de la base consolidada de paquetes de inversión.

## Abrir y editar

Abre `index.html` en un navegador, con los demás archivos en la misma carpeta. Selecciona una región en el mapa o en el selector, y usa los filtros de cartera para consultar los registros. El mapa representa los departamentos. Los códigos de inversión no se ubican en el mapa porque la base no contiene sus coordenadas.

El editor guarda los cambios en el almacenamiento de ese navegador. Usa las opciones de exportación para conservar una copia fuera del navegador. Los cambios locales no modifican la versión publicada ni se comparten con otros visitantes.

## GitHub Pages

El sitio es estático y no requiere un proceso de compilación. Para publicarlo desde la rama `main`, configura GitHub Pages con la raíz del repositorio como origen. Mantén `index.html` y los archivos que carga en la misma carpeta.

La aplicación muestra la fuente y la referencia de la geometría en el pie del mapa. Los campos territoriales y los aportes conservan el alcance registrado en la base de origen.
